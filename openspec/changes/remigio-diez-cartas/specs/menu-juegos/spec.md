## ADDED Requirements

### Requirement: El Remigio con las dos barajas
Como el Remigio se juega con la baraja española o, con la opción «Diez cartas», con la francesa, el menú MUST mostrarlo tanto con el filtro «Española» como con el filtro «Francesa».

#### Scenario: El Remigio con el filtro francesa
- **WHEN** el jugador elige el filtro «Francesa» y abre la familia «Combinaciones»
- **THEN** aparece el Remigio
